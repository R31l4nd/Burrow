# Regressions

Every problem that was reported (in the app, or in conversation) and the
automated test that now catches it. A problem is fixed only when it has a
test here that failed before the fix. `web/src/regressions.test.ts` checks
that each test named below exists, so a test cannot be removed or renamed
while this list still counts on it.

A test is named as `path :: title` (the title of a Playwright or Vitest test,
the name of a check in `e2e/tests/checks.ts`, or an Android test method).

## Kinds of problem, and the check that keeps each away everywhere

A reported layout problem is fixed where it was seen and then guarded on
every screen: these checks run in `lookAt` (e2e/tests/checks.ts) on each
screen of the tour (phone, desktop, Dutch at 343 px, dark, Dutch tablet, dark Dutch computer) and at the 11
sizes of workspace-sizes.spec.ts.
